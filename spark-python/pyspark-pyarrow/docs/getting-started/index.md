# Getting Started

This section covers everything you need to run the PySpark + PyArrow examples locally.

## Prerequisites

| Component | Version |
|-----------|---------|
| Python | 3.11+ |
| Java | 11 (LTS) — **required for Arrow** |
| Apache Spark / PySpark | 3.5.x |
| PyArrow | ≥ 14.0 |
| Pandas | ≥ 2.0 |

!!! tip "No cluster needed"

    All examples run in local mode — they work on your laptop in seconds.
