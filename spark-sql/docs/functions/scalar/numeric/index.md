# :material-calculator-variant: Numeric Functions

Functions for arithmetic, rounding, and low-level bit manipulation on numeric types.

______________________________________________________________________

## :material-book-open-variant: In This Section

| Page                  | Contents                                                                        |
| --------------------- | ------------------------------------------------------------------------------- |
| [Math](math.md)       | `ABS`, `ROUND`, `CEIL`, `FLOOR`, `MOD`, `POWER`, `SQRT`, `GREATEST`/`LEAST`     |
| [Bitwise](bitwise.md) | `BIT_AND`, `BIT_OR`, `BIT_XOR`, `SHIFTLEFT`, `SHIFTRIGHT`, `SHIFTRIGHTUNSIGNED` |

> **Rule of thumb:** use `Math` functions for everyday numeric transforms; use
> `Bitwise` functions only when you are directly manipulating integer bit
> patterns (flags, masks, low-level encodings).
